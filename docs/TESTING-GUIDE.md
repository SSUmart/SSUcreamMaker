# 온글 테스트 가이드 (팀원용)

`main` 브랜치의 온글을 직접 써 보는 방법입니다. 10분이면 됩니다.

## 1. 받기와 설치

```bash
git switch main && git pull
```

1. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → 저장소의 `extension` 폴더 선택
3. 설치되면 안내 음성이 나오고 설정 화면이 열립니다
4. 테스트하는 동안 NVDA·센스리더·VoiceOver는 꺼 주세요 (소리와 키가 겹칩니다)

> 코드를 다시 받았으면 `chrome://extensions`에서 온글의 새로고침(↻)을 누르고, 열어 둔 페이지는 F5로 새로고침합니다.

## 2. 테스트용 쇼핑몰 띄우기

```bash
cd eval
npm run shop
```

크롬에서 `http://127.0.0.1:8080/shop/` 을 엽니다. 이름 없는 버튼, 글자가 든 상세 이미지처럼 일반 스크린리더가 읽기 어려운 요소를 일부러 넣은 가짜 쇼핑몰입니다.

## 3. 기본 키

| 키 | 하는 일 |
|---|---|
| `Alt+Shift+O` | 온글 켜기·끄기 |
| `Alt+Shift+M` | 온글 메뉴 (첫 항목이 **사용 가이드**) |
| `Alt+Shift+X` / `Ctrl` | 읽기 멈춤 |
| `↓` `↑` | 다음·이전 항목 읽기 |
| `H` `K` `B` `F` | 다음 제목·링크·버튼·입력 요소 (`Shift`와 함께 누르면 이전) |
| `Enter` / `Space` | 누르기 |
| `Alt+Shift+1` | 키 도움말 |

온글 명령은 모두 `Alt+Shift`와 글자 키를 함께 누릅니다. macOS에서 `Alt`는 `Option` 키입니다. 온글은 안내할 때 "Alt와 Shift와 S"처럼 실제 키 이름을 읽습니다.

> `Alt+Shift`로 시작하는 키가 반응하지 않으면 원격 데스크톱·VDI 프로그램이나 Windows 입력 언어 전환 단축키(`Alt+Shift`)가 키를 먼저 가져가는지 확인하세요. Windows `설정 → 시간 및 언어 → 입력 → 고급 키보드 설정 → 입력 언어 핫키`에서 입력 언어 전환을 `Ctrl+Shift`나 "할당 안 됨"으로 바꾸면 됩니다. 그래도 안 되면 어떤 키가 안 되었는지와 환경(OS, VDI 여부, 입력기)을 알려 주세요.

모르는 게 있으면 `Alt+Shift+M` → **사용 가이드**를 고르세요. 위아래 화살표로 한 문단씩 읽어 줍니다.

## 4. 이것만 해 보세요

1. 쇼핑몰에서 `Alt+Shift+O`로 켜고 `↓`로 읽어 보기. 화면 아래 자막과 주황색 테두리가 따라오는지 확인
2. `B`를 여러 번 눌러 이름 없는 버튼 찾기. AI 설정 전에는 "이름 없음, 버튼"으로 읽습니다. 이름 없는 요소는 탭 안이 아니라 다음 자리에 있습니다
   - 공유 버튼: 상품명(제목 1) 바로 옆의 공유 아이콘
   - 옵션 초기화(휴지통) 버튼: 옵션 선택 영역의 수량 `+` 버튼 바로 뒤
   - "도움돼요" 버튼: 리뷰 탭 안, 리뷰마다
   - "최근 본 상품" 사진 링크: 본문 맨 끝
   - "맨 위로" 버튼: 화면 오른쪽 아래 둥근 버튼 (`div`로 만들어 `Tab`으로는 갈 수 없지만 온글은 `B`로 찾음)
3. 리뷰 탭으로 가서 `Enter`로 열고 읽어 보기
4. 편집창에서 `Enter`를 누르고 글 입력, `Esc`로 빠져나오기
5. 상세정보 탭에서 `↓`로 내려가면 상세 이미지 자리에서 "상세 이미지 4개, … Alt와 Shift와 D 키를 누르면 AI가 읽습니다"라고 알려 줍니다
6. (AI 설정 후) 이름 없는 버튼에 다시 가면 "공유하기, AI 추정, 버튼"처럼 읽습니다. `Alt+Shift+S` 요약(대화상자, `Esc`로 닫기), `Alt+Shift+Q` 질문, `Alt+Shift+D` 상세 이미지 읽기(상세 이미지 위에 결과 상자), `Alt+Shift+I` AI 결과 모음

## 5. AI 켜기 (선택)

`Alt+Shift+M` → **온글 설정** → **AI 사용**에서 AI 기능을 켜고 공급자를 고른 뒤 API 키를 넣습니다.

- Gemini: [Google AI Studio](https://aistudio.google.com/apikey)에서 무료 키 발급
- NVIDIA NIM: [build.nvidia.com](https://build.nvidia.com/)에서 키 발급 후 모델 선택

키는 내 크롬에만 저장됩니다. 키를 파일에 적거나 커밋하지 마세요.

## 6. 점자 확인 (관리자 도구)

점자 디스플레이가 없어도 됩니다. **온글 설정 → 점자 → 관리자 도구 켜기**를 켜면 화면에 **점자 전달 테스트** 버튼이 생깁니다. 누르면 가상 점자 디스플레이에 지금 읽는 글이 점자로 보이고, 보낸 데이터와 성공 여부도 함께 나옵니다.

## 7. 자동 점검 (개발자용, API 키 불필요)

```bash
npm test                          # 저장소 루트: 단위 테스트
cd eval
npm run e2e:reader                # 온글 전체 동작 (가짜 AI·가짜 음성)
npm run reader:accuracy           # 쇼핑몰 읽기 정확성 (정답표와 비교)
npm run braille                   # 한국 점자 규정 예문 비교
```

처음 한 번은 `cd eval && npm install && npx playwright install chromium`이 필요합니다.
