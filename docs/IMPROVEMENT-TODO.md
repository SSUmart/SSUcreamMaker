## 1. 옵션을 고르면 고른 값 알려 주기

> "페이지 옵션 선택할 때 어떻게 어떤 키를 통해 사용해야 하는지와 내가 선택한 게 어떤 건지 몰라 어려움이 있었습니다" (사용자)

처음에는 체크 상자·라디오·탭의 선택 상태만 읽고, 목록 항목(`role="option"`)의 `aria-selected`와 클래스로만 표시한 옵션은 읽지 않았습니다(`extension/content/reader/model.js`의 `statesOf`).

- [x] `role="option"`의 `aria-selected="true"`를 "선택됨"으로 읽는다. 단일 선택 목록에서 지금 가리키는 항목(`aria-activedescendant`)은 가리키는 것이 곧 고르는 것이라 따로 읽지 않는다(NVDA와 같음). 목록 상자는 고른 항목을 값으로 읽는다
- [x] ARIA 표시 없이 만든 옵션을 알아보는 규칙: 같은 모양 버튼 2개 이상 가운데 일부에만 "고름" 클래스(`on`, `active`, `selected`, `checked`, `current`, `is-…`, `…-selected` 등)가 붙어 있으면 "선택됨"으로 읽는다. `<li class="on"><button>`처럼 감싼 목록 항목에 붙은 표시도 본다. 모두 같은 클래스가 붙어 있으면 꾸밈으로 보고 읽지 않는다
- [ ] 위 규칙을 실제 쇼핑몰 2~3곳(네이버 쇼핑, 쿠팡 등)의 옵션 화면에서 확인하고 필요하면 고친다
- [x] 옵션을 누른 직후 고른 값을 이름과 함께 읽는다 ("250mm, 선택됨"). 가격처럼 다른 곳에 바뀐 글은 그 페이지가 실시간 안내 영역(`role="status"`)으로 알릴 때 이어 읽는다
- [x] 선택 상자(`C` 키)에서 Enter로 들어가면 "위아래 화살표로 항목을 고르면 고른 항목을 읽어 드립니다"라고 고르는 방법을 안내한다(글자를 치는 편집창 안내와 나눔)
- [x] E2E(`npm run e2e:reader`)에 옵션 확인 페이지(클래스로 표시한 사이즈 버튼, 목록 항목에 표시가 붙은 색상 버튼, `aria-selected` 목록 상자, 모두 같은 클래스인 꾸밈 버튼)와 온글몰 양말 사이즈 버튼 확인을 넣는다. 읽기 정확성 정답표(162/162)는 평가용 쇼핑몰에 바뀐 곳이 없어 그대로 통과

완료 기준: 온글몰과 조사한 실제 쇼핑몰에서 옵션을 고르면 무엇을 골랐는지 듣는다.

## 2. 상품 핵심 위치로 바로 가기

> "네이버 쇼핑 기준 화살표 이동을 50번 해야 상품 이동하는 동작까지 도달할 수 있었어요" (사용자)

영역 이동 키(`D`)와 영역 목록은 이미 있지만, 영역 표시(landmark)가 없는 사이트에서는 갈 곳이 없습니다.

- [x] 상품 페이지에서 상품명, 가격, 옵션, 수량, 구매·장바구니 버튼을 찾는 규칙을 만든다 (`extension/content/reader/product.js`). 구조화 데이터(JSON-LD `schema.org/Product`, `og:title`, `product:price:amount`)의 상품명·가격을 먼저 쓰고, 없으면 첫 1수준 제목, 상품명 뒤 첫 "○○원" 글, 선택 상자·라디오 묶음·옵션 버튼 묶음(앞 글에 "사이즈", "색상" 등), 이름에 "수량"이 든 입력칸, "바로 구매"·"장바구니" 버튼을 찾는다. 머리말·메뉴·바닥글 안과 "구매 후기" 같은 것은 뺀다
- [x] 온글 메뉴에 "상품 핵심 정보" 목록을 넣는다. 고르면 그 위치로 이동해 이어 읽는다
- [x] 키 하나로 연다: `Alt+Shift+P`. 키 도움말, 사용 가이드, 설치 가이드, README에 넣음
- [x] 찾지 못하면 "상품 정보를 찾지 못했습니다. 제목 목록이나 링크 목록, 또는 B 키로 버튼을 찾아 보세요"라고 알리고 온글 메뉴로 돌아간다
- [ ] 규칙으로 못 찾을 때 AI(요약의 근거 위치)로 보완할지 정한다 (실제 쇼핑몰 확인 뒤)
- [ ] 실제 쇼핑몰 2~3곳(네이버 쇼핑 등)에서 목록이 맞게 나오는지, 구매 버튼까지 누른 키 수를 고치기 전과 뒤로 잰다

온글몰 텀블러 상품에서는 `Alt+Shift+P` → 위 화살표 두 번 → `Enter`, **키 네 번**으로 "바로 구매" 버튼에 갑니다(읽기 E2E로 확인).

완료 기준: 네이버 쇼핑 상품 페이지에서 구매·장바구니 버튼까지 키 다섯 번 안에 간다.
