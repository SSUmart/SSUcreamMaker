# 수정 요약: `fix/review-findings`

26.2.0 정식 릴리즈 뒤 코드 리뷰와 QA에서 찾은 문제를 고친 브랜치입니다. 자세한 내용은 `CHANGELOG.md`의 `[Unreleased]`에 있습니다.

## 읽기·키보드

| 문제 | 고친 방법 |
|---|---|
| 글쓰기 모드(편집창, 선택 상자 등)에서 `Alt+Shift+S`·`Q`·`D`·`E`·`I`·`1` 같은 온글 명령이 반응하지 않음 | 온글 명령은 글쓰기 모드에서도 받는다. 명령이 아닌 `Alt+Shift` 조합과 `Alt+Shift+↓`(문단 선택)는 입력창에 그대로 넘김 |
| 계속 읽기를 다시 시작하면 읽는 위치 테두리·스크롤이 따라가지 않음 | 계속 읽기마다 번호를 매겨, 앞선 계속 읽기가 늦게 끝나도 새 계속 읽기를 방해하지 않게 함 |
| 글쓰기 모드에서 Tab으로 버튼에 가면 자막의 모드 표시가 한 박자 늦게 바뀜 | 모드를 먼저 바꾼 뒤 항목을 읽음 |
| 확장을 업데이트·새로고침한 뒤 이미 열린 탭에서 안내·도움말이 소리 없이 실패 | 예전 온글이 남아 있으면 모두 비우고 새로 정의함 |

## AI 기능

| 문제 | 고친 방법 |
|---|---|
| NVIDIA NIM 상세 이미지 읽기가 실패해도 남은 조각 요청이 계속 나가고, 진행 안내가 오류 안내를 덮음 | 한 조각이 실패하면 나머지 요청을 멈추고, 끝난 작업의 진행 안내는 무시함 |
| 같은 페이지에서 다시 요약하면 그 사이 글이 바뀌었어도(상세 이미지를 읽은 뒤 등) 예전 요약만 열림 | 요약할 때 보낸 글과 지금 글이 다르면 새로 요약함 |
| 질문의 답을 기다리다 대화상자를 닫으면 답이 소리 없이 사라짐 | 요약처럼 대화상자를 다시 열어 답을 읽음 |
| 온글을 끈 상태(다른 스크린리더 사용)에서 질문의 답·오류가 알려지지 않음 | 대화상자 안에 안내 영역을 따로 두고 그곳으로 알림 |
| 오류 안내에 영어·서버 응답 원문(주소·쿼리 포함)이 그대로 읽힘 | 상태별 한국어 안내로 바꾸고(서버 문제, 요청 거절, 모델·주소·키 확인, 응답 형식 오류, 연결 실패), 원문은 개발자 콘솔에만 남김 |
| 현재 항목 AI 설명(`Alt+Shift+E`)을 두 번 누르면 요청 2번, 결과도 2번 읽음 | 기다리는 중이면 "이미 만드는 중"이라고 알리고 다시 보내지 않음 |
| 상세 이미지를 읽는 중에 요약·질문 대화상자를 열면 진행 안내가 끼어들고, 끝나면 대화상자를 닫아 버림 | 대화상자가 열려 있는 동안은 진행 안내를 읽지 않고 닫지 않음. 끝나면 짧게 알리고, 사용자가 닫을 때 결과를 읽음. 원문·근거 위치로 이동하며 닫으면 그 위치를 그대로 둠 |

## 개인정보

| 문제 | 고친 방법 |
|---|---|
| 요약·질문이 웹메일 작성창, 댓글·문서 편집기에 쓰던 글까지 AI로 보냄 | 편집 영역(`contenteditable`, `role="textbox"` 등)은 보내지 않음 |
| 이름 없는 항목 자동 분석이 그림 주소와 `data-action` 값을 쿼리째(서명·토큰·회원 번호 등) 보냄 | 쿼리(`?…`)와 조각(`#…`)을 떼고 보냄 |

## 점자

| 문제 | 고친 방법 |
|---|---|
| 긴 항목을 읽는 중에 페이지 알림이나 온글 안내가 오면 디스플레이가 1번째 줄로 돌아가 읽던 위치를 잃음 | NVDA의 점자 메시지처럼, 안내·알림은 4초 동안 보인 뒤 읽던 항목과 읽던 줄로 돌아감. 알림 안에서 줄 넘기기가 되고, 커서 이동 버튼은 알림을 닫음 |
| 점자 칸 수나 점자 규칙을 바꾸면 줄을 넘길 때 "칸 수가 맞지 않습니다"로 실패 | 설정이 바뀌면 바로 다시 나누고 읽던 글자가 든 줄을 보임 |
| `It's`, `don't`의 아포스트로피를 작은따옴표로 바꿔 로마자가 끊기고 뒤 따옴표 짝이 뒤바뀜 | 로마자 사이의 아포스트로피는 3점으로 적음 (한국 점자 규정 제61항) |
| `ㅋㅋ`, `ㅠㅠ`, `ㄱㄴㄷ` 같은 낱자를 "모르는 글자"로 적음 | 온표와 받침으로 적고(제8항), 낱말에 붙은 자음은 456점을 앞세워 적음(제10항) |

## 팀원이 알아 둘 동작 변화

| 바뀐 점 | 내용 |
|---|---|
| 글쓰기 모드의 온글 명령 | 편집창에서도 `Alt+Shift`+기능 키가 온글 명령으로 동작함. 그래서 온글이 켜져 있으면 macOS에서 명령 글자(A·D·E·I·M·O·Q·R·S·X·1·Space)로 만드는 `Option+Shift` 특수 문자는 입력할 수 없음 |
| 점자 알림 | 안내·알림은 점자에서 4초 동안만 보이고 원래 항목으로 돌아감 (음성과 화면 자막은 전과 같음) |
| 대화상자 우선 | 요약·질문 대화상자가 열려 있으면 상세 이미지 읽기가 끼어들지 않음 |
