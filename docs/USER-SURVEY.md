# 온글 사용자 만족도 설문 문항

온글을 직접 써 본 사람이 자기 경험을 돌아보며 답하는 설문입니다. 아래 **문항 30개**를 모아 두었으니, 시험 목적에 맞게 **10개 안팎을 골라** 설문지를 만듭니다. 바로 쓸 수 있는 10문항 구성 예도 끝에 붙였습니다.

고른 문항은 [평가 설문 서비스](SURVEY-SERVICE.md)의 "새 설문 만들기"에 붙여 넣으면 됩니다. 영역 제목은 `# 시작하기`처럼 `#`과 띄어쓰기를 앞에 붙이고, 문항은 한 줄에 하나씩 씁니다(번호는 그대로 둬도 됩니다). 같은 설문을 팀원·사용자 링크와 AI에 함께 물어 세 점수를 비교할 수 있습니다.

같은 설문을 AI 두 개(Claude, ChatGPT)에 물은 결과는 [AI-SURVEY-EVALUATION.md](AI-SURVEY-EVALUATION.md)에 있습니다. 평가 계획 전체는 [EVALUATION-PLAN.md](EVALUATION-PLAN.md)를, 사용자 테스트에서 쓸 가상 쇼핑몰은 [eval/README.md](../eval/README.md#가상-쇼핑몰-온글몰-mall-주문결제까지)를 참고하세요.

## 점수

모든 문항은 같은 5점 척도로 답합니다.

| 점수 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 뜻 | 매우 불만족 | 불만족 | 보통 | 만족 | 매우 만족 |

- 응답자에게는 "해당 없음" 선택지를 두지 않습니다. 모든 문항에 1~5점으로 답하므로, 응답자가 실제로 써 본 기능만 문항으로 고릅니다. (AI 평가에서만 확인할 수 없는 기능을 해당 없음으로 받고 평균에서 뺍니다)
- 점수만으로는 이유를 알 수 없으므로, 문항마다 "그렇게 답한 이유(선택)" 칸을 두면 좋습니다.

## 설문지를 만들 때 지킬 것

응답자 중에는 스크린리더나 점자 디스플레이로 설문을 읽는 사람이 있습니다. 설문지 자체가 읽기 어려우면 온글이 아니라 설문지를 평가하게 됩니다.

- 문항마다 점수 버튼을 하나의 묶음(라디오 버튼)으로 만들고, 버튼마다 "1점 매우 불만족"처럼 점수와 뜻을 함께 적습니다. 숫자만 적으면 스크린리더가 "1, 라디오 버튼"으로만 읽습니다.
- 문항을 그림이나 표 속 글자로 넣지 않습니다.
- 한 페이지에 문항을 모두 넣고, 필수 응답은 최소로 둡니다. 빠진 문항이 있을 때 어떤 문항인지 글로 알려 주는 설문 도구를 씁니다. 평가 설문 서비스는 이 조건을 갖췄습니다.
- 응답 시간은 10문항 기준 10분 안팎으로 잡고, 원하면 진행자가 문항을 읽어 주고 대신 기록합니다.

## 응답자 정보 (점수 문항 아님)

결과를 나눠 볼 때 씁니다. 필요한 것만 묻습니다.

- 평소 쓰는 보조기기: 스크린리더(센스리더, NVDA, VoiceOver 등) / 점자 디스플레이 / 화면 확대 / 쓰지 않음
- 스크린리더 사용 경력: 쓰지 않음 / 1년 미만 / 1~5년 / 5년 이상
- 온글을 쓴 환경: Windows / macOS
- 이번에 해 본 일: 일반 웹페이지 읽기 / 가상 쇼핑몰(온글몰)에서 주문 / AI 기능(요약, 질문, 상세 이미지 읽기)

## 문항 30개

각 문항은 "얼마나 만족하셨나요?"로 끝납니다. 괄호 안은 그 문항으로 확인하려는 것입니다.

### A. 시작하기 (5문항)

| 번호 | 문항 | 확인하려는 것 |
|---|---|---|
| A1 | 온글을 설치하고 처음 켤 때까지의 과정에 얼마나 만족하셨나요? | 설치 장벽 |
| A2 | 온글을 켰을 때 들은 첫 안내만으로 무엇을 해야 할지 알 수 있었던 점에 얼마나 만족하셨나요? | 켜기 안내 |
| A3 | 크롬 첫 화면이 google.com으로 바뀐 이유와 되돌리는 방법을 안내받은 방식에 얼마나 만족하셨나요? | 새 탭 질문 |
| A4 | 사용 가이드로 온글의 기본 조작을 익히는 과정에 얼마나 만족하셨나요? | 사용 가이드 |
| A5 | 필요한 키를 잊었을 때 키 도움말 목록에서 찾아 다시 들을 수 있었던 점에 얼마나 만족하셨나요? | 키 도움말 |

### B. 읽기와 이동 (7문항)

| 번호 | 문항 | 확인하려는 것 |
|---|---|---|
| B1 | 온글이 웹페이지 글을 빠짐없이, 올바른 순서로 읽어 준 점에 얼마나 만족하셨나요? | 읽기 정확성 |
| B2 | 제목·링크·버튼 등을 한 글자 키(H, K, B 등)로 건너뛰며 원하는 곳을 찾는 데 얼마나 만족하셨나요? | 빠른 이동 |
| B3 | 각 항목이 무엇인지(제목, 링크, 버튼, 체크박스 등)와 상태(선택됨, 펼쳐짐 등)를 알려 주는 방식에 얼마나 만족하셨나요? | 역할·상태 안내 |
| B4 | 검색창이나 입력칸에 들어가 글을 쓰고 다시 읽기로 돌아오는 과정에 얼마나 만족하셨나요? | 읽기·글쓰기 모드 |
| B5 | 한/영 키(맥은 Caps Lock)를 눌렀을 때 바뀐 입력 언어를 알려 준 점에 얼마나 만족하셨나요? | 입력 언어 안내 |
| B6 | 온글 메뉴에서 원하는 기능을 목록으로 찾아 실행하는 과정에 얼마나 만족하셨나요? | 온글 메뉴 |
| B7 | 기존에 쓰던 스크린리더(센스리더, NVDA 등)와 비교해 조작 방식이 익숙하게 느껴진 점에 얼마나 만족하셨나요? | 기존 습관과의 일치 |

### C. 출력 (4문항)

| 번호 | 문항 | 확인하려는 것 |
|---|---|---|
| C1 | 음성의 속도와 발음, 알아듣기 쉬운 정도에 얼마나 만족하셨나요? | 음성 |
| C2 | 안내 문장이 짧고 이해하기 쉬웠던 점에 얼마나 만족하셨나요? | 문장 품질 |
| C3 | 읽는 글을 화면 자막과 테두리로 함께 보여 주는 방식에 얼마나 만족하셨나요? (화면을 일부 볼 수 있거나 옆에서 도와주는 사람 기준) | 화면 오버레이 |
| C4 | 같은 내용을 점자로도 받을 수 있는 점에 얼마나 만족하셨나요? (점자 디스플레이 사용자 기준) | 점자 출력 |

### D. AI 기능 (8문항)

| 번호 | 문항 | 확인하려는 것 |
|---|---|---|
| D1 | 이름 없는 버튼이나 그림을 AI가 무엇인지 채워 읽어 준 점에 얼마나 만족하셨나요? | 자동 보완 |
| D2 | AI가 채운 내용에 "AI 추정"이라고 구분해 알려 준 방식에 얼마나 만족하셨나요? | AI 결과 표시 |
| D3 | 상품 상세 이미지 속 글자(가격, 옵션, 주의사항 등)를 읽어 준 결과에 얼마나 만족하셨나요? | 상세 이미지 읽기 |
| D4 | 긴 페이지를 몇 가지 핵심으로 요약해 준 내용에 얼마나 만족하셨나요? | 페이지 요약 |
| D5 | 페이지에 질문했을 때(예: "배송비 얼마야?") 받은 답의 정확도에 얼마나 만족하셨나요? | 질문 응답 |
| D6 | 요약이나 답에서 근거가 된 원문 위치로 바로 이동할 수 있었던 점에 얼마나 만족하셨나요? | 근거 확인 |
| D7 | AI 결과가 나올 때까지 기다리는 시간과, 기다리는 동안의 안내에 얼마나 만족하셨나요? | 응답 속도·대기 안내 |
| D8 | 삭제·결제처럼 되돌리기 어려운 동작일 수 있는 이름 없는 버튼에 "용도 불명확, 삭제 관련일 수 있음"처럼 조심하라고 알려 준 점에 얼마나 만족하셨나요? | 파괴적 버튼 교차 검증 |

> **D7 해석 주의:** 테스트 서버(`ssu.jaymong.me`)의 온글몰에서는 상세 이미지 읽기가 시연용 저장 결과로 바로 나옵니다. 이 서버에서 받은 D7 점수는 실제 AI 대기 시간을 반영하지 않습니다.

### E. 실제 과제: 쇼핑하기 (3문항)

온글몰처럼 상품을 고르고 주문하는 과제를 해 본 경우에 묻습니다.

| 번호 | 문항 | 확인하려는 것 |
|---|---|---|
| E1 | 상품을 찾고 가격, 옵션, 상세 정보를 확인하는 과정에 얼마나 만족하셨나요? | 상품 탐색 |
| E2 | 옵션을 고르고 장바구니에 담는 과정에 얼마나 만족하셨나요? | 옵션·장바구니 |
| E3 | 배송지와 결제수단을 입력하고 주문을 끝까지 마치는 과정에 얼마나 만족하셨나요? | 주문서·결제 |

### F. 종합 (3문항)

| 번호 | 문항 | 확인하려는 것 |
|---|---|---|
| F1 | 다른 사람의 도움 없이 혼자서 원하는 일을 해낼 수 있었던 점에 얼마나 만족하셨나요? | 독립적 사용 |
| F2 | 온글을 전체적으로 써 본 경험에 얼마나 만족하셨나요? | 전체 만족도 |
| F3 | 온글을 앞으로도 쓰거나 주변에 추천하고 싶은 정도에 얼마나 만족하셨나요? | 재사용·추천 의향 |

## 주관식 문항 (선택)

점수 문항 뒤에 두세 개만 붙입니다.

1. 온글로 해 본 일 가운데 가장 편했던 것은 무엇인가요?
2. 막히거나 답답했던 순간이 있었다면 언제, 무엇 때문이었나요?
3. 온글에 꼭 더해졌으면 하는 기능이나 바꿨으면 하는 점이 있나요?

## 결과 정리

- 문항별 평균과 응답 수를 냅니다. AI 답의 "해당 없음"은 평균에서 뺍니다.
- 4점 이상 비율(만족 비율)을 함께 봅니다. 응답자가 적을 때는 평균보다 이해하기 쉽습니다.
- 응답자 정보(스크린리더 경력, 보조기기)별로 나눠 보면, 처음 쓰는 사람과 숙련자가 어디서 다르게 느끼는지 알 수 있습니다.
- 3점 이하 문항은 주관식 답과 함께 읽고 개선 과제로 옮깁니다.
