SSUcreamMaker 설정

웹페이지에서 아래 단축키를 누르면 AI가 페이지를 읽기 쉽게 도와줍니다.

  • Alt+Shift+D: 상세 이미지 속 글자를 읽어 페이지에 텍스트로 넣기
  • Alt+Shift+S: 페이지 내용 요약
  • Alt+Shift+Q: 페이지에 질문하기

단축키는 브라우저 주소창에 chrome://extensions/shortcuts 를 입력해 바꿀 수 있습니다.

AI 사용

켜면 단축키를 누를 때마다 상세 이미지나 페이지 글이 아래에서 선택한 AI 서비스로 전송되고, 사용 요금은 입력한 API 키의 계정에 청구됩니다. 입력창에 적은 내용은 보내지 않습니다. Google Gemini 무료 등급은 보낸 내용이 Google의 서비스 개선에 쓰일 수 있으니, 개인정보가 있는 페이지에서는 쓰지 마세요.
