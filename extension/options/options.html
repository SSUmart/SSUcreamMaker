SSUcreamMaker 설정

웹페이지에서 아래 단축키를 누르면 AI가 페이지를 읽기 쉽게 도와줍니다.

  • Alt+Shift+D: 상세 이미지 속 글자를 읽어 페이지에 텍스트로 넣기
  • Alt+Shift+S: 페이지 내용 요약
  • Alt+Shift+Q: 페이지에 질문하기
  • Alt+Shift+E: 항목 설명 모드 켜기/끄기 (켜진 동안 클릭한 항목을 AI가 설명, 시험 기능)

단축키는 브라우저 주소창에 chrome://extensions/shortcuts 를 입력해 바꿀 수 있습니다.

AI 사용

켜면 단축키를 누를 때마다(항목 설명 모드에서는 항목을 클릭할 때마다) 상세 이미지, 페이지 글, 고른 항목의 글자·그림이 아래에서 선택한 AI 서비스로 전송되고, 사용 요금은 입력한 API 키의 계정에 청구됩니다. 입력창에 적은 내용은 보내지 않습니다. Google Gemini 무료 등급은 보낸 내용이 Google의 서비스 개선에 쓰일 수 있으니, 개인정보가 있는 페이지에서는 쓰지 마세요.

NVIDIA NIM은 모델이 자주 바뀌어 기본 모델이 없습니다. 목록은 이미지 입력을 받고 현재 제공 중인 추천 후보입니다(2026년 10월 14일 확인). 한국어 글자 인식 품질은 아직 비교하지 않았으니 상세 이미지 읽기로 확인해 보세요. 목록에 없는 모델은 "직접 입력"을 고르세요.

API 키는 이 컴퓨터의 브라우저에만 저장되며 다른 기기와 동기화되지 않습니다.
