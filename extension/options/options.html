온글 설정

온글은 AI를 결합한 웹 스크린리더입니다. 웹페이지를 읽어 화면 위 자막, 음성, 점자 디스플레이로 전하고, 읽을 수 없는 부분은 AI로 채웁니다. 온글을 쓰는 동안 NVDA나 센스리더 같은 다른 스크린리더는 꺼 주세요.

시작하기

  1. NVDA나 센스리더 같은 다른 스크린리더를 끕니다.
  2. 온글 켜기 단축키를 누릅니다.
  3. 온글 메뉴 단축키를 누르고, 첫 항목 "사용 가이드"에서 사용법을 듣습니다.
  4. AI 기능(이름 없는 항목 분석, 요약, 질문, 상세 이미지 읽기)을 쓰려면 아래 "AI 사용"에서 AI를 켜고 API 키를 넣은 뒤 저장합니다.

크롬 단축키

온글의 모든 명령은 Alt+Shift(macOS는 Option+Shift)와 글자 키를 함께 누릅니다. 아래 네 단축키는 웹페이지 밖(주소창 등)에서도 동작하고, 그 밖의 명령(요약, 질문 등)은 웹페이지 안에서 동작합니다. 모든 기능은 온글 메뉴에서도 고를 수 있습니다.

이 네 단축키를 바꾸려면 주소창에 chrome://extensions/shortcuts 를 입력합니다. 이 화면은 크롬 설정 화면이라 온글이 읽을 수 없으므로, 다른 스크린리더나 주변 사람의 도움이 필요합니다. 기능 키 글자는 아래에서 온글로 바꿀 수 있습니다.

기능 키

Alt+Shift와 함께 눌러 실행할 글자입니다. 서로 다른 글자여야 하고, A(계속 읽기), R(다시 읽기), X(읽기 멈춤), O(켜기/끄기), I(AI 결과 모음)는 쓸 수 없습니다. 그 밖에 Alt+Shift와 아래 화살표는 계속 읽기, 스페이스는 읽기·글쓰기 모드 전환, 1은 키 도움말입니다.

안내

안내를 얼마나 자세히 읽을까요?

오류나 막힌 상황(읽을 수 없는 페이지, 초점이 주소창에 있을 때 등)의 안내는 설정과 관계없이 항상 자세히 읽습니다.

점자

점자 규칙

켜면 화면 오른쪽 아래에 "점자 전달 테스트" 버튼이 생기고, 온글 메뉴에도 같은 항목이 생깁니다. 누르면 가상 점자 디스플레이와 전달 결과(보낸 원문, 점자 변환, 보낸 데이터, 전송 결과, 기기 신호 왕복)를 보여 줍니다. 끄면 온글은 일반 스크린리더로만 동작합니다.

음성

AI 사용

켜면 이름이 없어 읽을 수 없는 버튼, 링크, 그림을 읽을 때 AI가 자동으로 분석해 이름을 붙입니다(AI 기능이 켜져 있을 때만). 그 항목의 글자, 주변 글, 그림이 AI로 전송됩니다. 페이지를 열면 앞쪽 다섯 개는 미리 분석하고, 한 페이지에서 최대 30개까지 분석합니다.

켜면 단축키를 누를 때마다(항목 설명 모드에서는 항목을 클릭할 때마다) 상세 이미지, 페이지 글, 고른 항목의 글자·그림이 아래에서 선택한 AI 서비스로 전송되고, 사용 요금은 입력한 API 키의 계정에 청구됩니다. 입력창에 적은 내용은 보내지 않습니다. Google Gemini 무료 등급은 보낸 내용이 Google의 서비스 개선에 쓰일 수 있으니, 개인정보가 있는 페이지에서는 쓰지 마세요.

NVIDIA NIM은 모델이 자주 바뀌어 기본 모델이 없습니다. 목록은 이미지 입력을 받고 현재 제공 중인 추천 후보입니다(2026년 10월 14일 확인). 한국어 글자 인식 품질은 아직 비교하지 않았으니 상세 이미지 읽기로 확인해 보세요. 목록에 없는 모델은 "직접 입력"을 고르세요.

API 키는 이 컴퓨터의 브라우저에만 저장되며 다른 기기와 동기화되지 않습니다.
